# Dự án Phân tích Giao dịch (Dự án: Transaction Analysis Project)

Dự án này sử dụng mô hình Học máy (Machine Learning) để phân tích dữ liệu giao dịch và dự đoán gian lận. 

## ⚠️ Lưu ý quan trọng về Dữ liệu (Data)
Vì file dữ liệu của dự án quá lớn (hơn 300MB) nên không thể tải trực tiếp lên GitHub. Để chạy được code trong dự án này, vui lòng làm theo các bước sau:

**Bước 1: Tải dữ liệu**
* Vui lòng tải các file dữ liệu lớn tại link Google Drive sau: **[Link Google Drive chứa các file]**
* Các file cần tải: `transactions_data_10pc.csv`, `transactions_data_25pc.csv`, `train_fraud_labels.csv`.

**Bước 2: Cài đặt**
* Tải toàn bộ code trên kho lưu trữ này về máy (Code/Download ZIP).
* Đặt các file dữ liệu (CSV) vừa tải ở Bước 1 vào chung thư mục chứa file `1.ipynb`.

**Bước 3: Chạy ứng dụng**
* Mở file `1.ipynb` bằng Jupyter Notebook hoặc VS Code và Run All.
* Hoặc chạy file `app.py` / `run_dashboard.bat` để mở giao diện.
